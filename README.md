# RaceSponsor Pro

**The Premier Real-Time Athlete Sponsorship Marketplace & Live Auction SaaS Platform.**

RaceSponsor Pro enables brands and corporate sponsors to bid directly on on-body decal placements, singlet patches, and bundled social media deliverables for elite endurance and fitness athletes competing in **HYROX**, **CrossFit**, **Triathlon**, and **Combat Sports**.

---

## ⚡ Key Features

- **Founder & Headliner Spotlight**: Dedicated showcase for platform founder **Jaffet Corona** (HYROX Anaheim 2026, Dec 6).
- **Interactive On-Body Decal Map**: Real photorealistic anatomical **Front & Back** views of the athlete with interactive, clickable decal placement hotspots.
- **Live Bidding Terminal**: Anti-sniping engine extending cutoff times by +60 seconds on late bids.
- **Strict 14-Day Pre-Race Cutoff**: Hard bidding closing window ensuring ample lead time for vector printing and medical-grade temporary tattoo production.
- **Athlete Intake Application**: Multi-step submission funnel for verified athletes.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS & Lucide Icons
- **Animation**: Framer Motion & Studio Freight Lenis Smooth Scroll
- **State Management**: Zustand
- **Font**: Inter & JetBrains Mono

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
